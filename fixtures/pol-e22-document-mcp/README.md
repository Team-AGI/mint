# MINT E-22 Document MCP

이 서버는 POL-E-22 검증을 위한 고정 시험 문서 한 개를 제공합니다.

| 도구 | 동작 |
| --- | --- |
| `get_test_document` | 시험 문서와 누적 변경 횟수를 조회합니다. |
| `append_test_line` | 시험 문서에 최대 120자의 한 줄을 추가합니다. |

문서 경로는 도구 입력으로 받지 않습니다. Windows에서는 직원 프로필의 `LOCALAPPDATA/MINT-E22-Document-Test`에 SQLite 상태를 저장합니다. 독립 실행 시 `E22_STATE_DIR`로 시험 전용 디렉터리를 지정할 수 있습니다. 서버는 동일한 문구도 호출마다 한 번 추가하므로, 게이트웨이가 중복을 차단했는지 변경 횟수로 확인할 수 있습니다. 상태는 32줄로 제한합니다.

Python 3.12 이상에서 `python -m pip install .`을 실행하면 `mint-e22-document-mcp` 명령으로 stdio 서버를 시작할 수 있습니다.

MINT 도입은 소스 검증과 관리자 승인을 거칩니다. 시험에서는 두 도구의 읽기·쓰기 분류와 직원 계정 범위를 확인한 뒤, 같은 쓰기 요청을 두 번 보내고 읽기 도구에서 변경 횟수가 한 번만 증가했는지 확인합니다. 같은 요청 식별자에 서로 다른 인자를 넣는 케이스는 호출 경로가 해당 식별자를 실제로 사용함을 확인한 뒤 검증합니다.
